# 音频提取（零拷贝极简 Android 工具）

专为小米手机（Android 10+ / HyperOS / MIUI）设计的超轻量视频音频提取工具：

- **真正零拷贝**：使用 Android 原生 `MediaExtractor` + `MediaMuxer` 直接流式抽取视频音轨，不拷贝几个 G 的原视频，不占额外临时空间，几 GB 长视频通常几秒抽完。
- **体积超小**：不内置 FFmpeg，Release APK 仅约 1.5~2.5 MB。
- **分享即提取**：支持系统 `分享` 菜单单选 / 多选视频一键抽取，也支持打开 App 手动选文件。
- **防杀后台**：使用前台服务 + 通知栏实时进度条，切后台也能稳稳跑完。
- **自动入库**：无损输出 `.m4a` 保存至 `Music/提取音频/`，重名自动编号，音乐 App 和文件管理立即可见。
- **内置轻量剪辑**：支持对已提取或手机本地任意音频进行试听预览、双滑块 + 微调精确截取、手动设置**开头渐强（0~15s）**与**末尾渐弱收尾（0~15s）**，导出另存为 `原名_剪辑.m4a`。

## 一、用 GitHub Actions 云端一键打包 APK（无需装 Android 环境）

1. 在 GitHub 上新建一个空仓库（**公开或私有都可以**）。
2. 将本项目所有文件上传（`git push`）到仓库的 `main` 或 `master` 分支：
   ```bash
   git init
   git add .
   git commit -m "init: AudioExtractor"
   git branch -M main
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面 → 点击顶部 **Actions** 标签 → 等待约 2 分钟，看到绿色勾后点进去。
4. 在页面最底部的 **Artifacts** 区域下载 `AudioExtractor-APK.zip`，解压得到 `AudioExtractor-release.apk`。

---

## 二、小米手机安装与使用

1. 把 `AudioExtractor-release.apk` 传到小米手机并点击安装（如提示“未知来源”或安全守护提示，点继续安装即可）。
2. **日常用法（推荐）**：
   - 在小米 **相册** 或 **文件管理** 中选中 1 个或多个 MP4 视频
   - 点击 **分享** → 选择 **音频提取**
   - 自动开始无损提取，几秒后音频会保存到 **`Music/提取音频/`**
3. **手动选择与历史记录**：
   - 桌面点击 **音频提取** 图标，可手动多选视频，也可查看最近提取记录（点击条目直接播放，点右侧“分享”可直接把音频发到微信等 App）。

## 三、常见问题

- **为什么输出是 `.m4a` 而不是 `.mp3`？**
  MP4 视频里的音轨 99% 本身就是 AAC 编码，无损直出 `.m4a` 不重新编码，**音质 100% 无损且速度是转码的几十倍**，对几个 G 的长视频最友好，手机音乐 App、微信、电脑播放器均原生支持。
- **如果遇到极少数视频提示不支持该音轨格式？**
  说明该视频内嵌了非标准 MP4 音频编码（如 AC3/PCM/Opus），原生 `MediaMuxer` 无法无损封装为 `.m4a`。
